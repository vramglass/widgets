# Contributing

This repository contains the integration SDK for the hosted VRAMGlass widget. Keep changes focused on loading, integration and documentation. Do not import rendering code, price collection, credentials or datasets from the VRAMGlass website.

Run `npm test` and `npm run verify:package`. Test browser-facing changes with the HTML example and document browser/version and results. Report routine bugs through repository Issues . Security reports go to hello@vramglass.com; do not post credentials or vulnerabilities publicly.
