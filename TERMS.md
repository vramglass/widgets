# Hosted widget usage

Embedding VRAMGlass hosted widgets or using the associated data service requires keeping the VRAMGlass mark and source attribution clear, visible and clickable. Do not remove, obscure, crop, overlay or replace the attribution, disable the link, or change its destination to another site. This includes modifications made with CSS or scripts.

You may add `nofollow` to a source link. It does not waive visible attribution or functional linking requirements. These conditions apply to the hosted service, separately from any SDK code license. An SDK license does not license the hosted renderer, database, bulk data feed or brand assets.

The service is provided without an availability guarantee and may change or be rate-limited. For custom or white-label use, contact hello@vramglass.com.
